# kmark ページ番号表示テスト 1

このファイルは、kmark のページ番号表示を確認するためのテスト Markdown です。

このテストでは、kmark 拡張パラを以下の形式で書きます。

```text
<!-- kmark { page_number:bottom-center page_number_format:"{page}" } -->
...
<!-- kmark } -->
```

確認すること:

- `page_number:bottom-center` で下中央にページ番号が出る
- `page_number_format:"{page}"` で現在ページ番号だけが出る
- ページ番号が本文と重ならない
- プレビューと印刷で位置が一致する

## 通常文章

ページ番号は Markdown 本文の一部ではなく、ページ装飾として扱われる想定です。  
そのため、見出し、段落、表、コードブロック、手動ページ割、自動ページ割に影響されず、各ページの決められた位置に表示される必要があります。

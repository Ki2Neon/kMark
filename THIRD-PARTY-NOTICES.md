# Third-Party Notices

kMark itself is licensed under MIT. Third-party components keep their own licenses.

This file records the dependency licenses confirmed in this repository on 2026-08-06.

## Notes

- `dompurify` is dual-licensed under `MPL-2.0 OR Apache-2.0`. For kMark distribution, the Apache-2.0 option is selected.
- Tauri crates and packages used directly by this app are `MIT OR Apache-2.0`.
- Some Rust transitive dependencies include `MPL-2.0`. Those do not prevent kMark itself from using MIT, but their original license terms still apply to those third-party components.

## Bundled PlantUML standard libraries

kMark includes the 33 browser standard-library bundles generated by PlantUML core `1.2026.6` at upstream commit `6287b33c5d1be2f7b0d480687d0b5a1accbd7971`.

- Exact source repository, version, reported license, byte size, and SHA-256: `src/adapters/browser/plantumlStdlibManifest.json`
- Vendored generated assets: `vendor/plantuml-stdlib`
- The manifest preserves empty license fields where the upstream generated metadata does not declare a license. No license is inferred for those entries.
- Explicit licenses reported by the generated metadata include GPL for AdaML, MIT for Archimate and C4, MIT License for Bootstrap and DomainStory, and Apache License 2.0 for Material 7.4.47.

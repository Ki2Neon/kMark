# kMark

超軽量な Markdown エディターです。Vite + React + Tauri で構成し、機能は次の 4 つに絞っています。

- ライブプレビュー
- Split / Write / Preview の表示切り替え
- ローカル下書きの自動保持
- Markdown ファイルの読み込みと書き出し

## 開発

```bash
pnpm install
pnpm run dev
```

## Tauri アプリとして起動

```bash
pnpm run tauri dev
```
